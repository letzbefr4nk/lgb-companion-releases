# LGB Companion releases

Windows installers and update files for LGB Companion, a companion app for members of the Let's Game Boys Discord server.

Download the latest `lgb-companion-<version>-setup.exe` from [Releases](https://github.com/letzbefr4nk/lgb-companion-releases/releases/latest). The app updates itself after that.

The app's source code is private; this repo holds only the release files.
