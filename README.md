# LGB Companion

Windows installers and update files for LGB Companion, the Let's Game Boys Discord server's
companion app.

## Install

1. Open **Releases** on the right of this page (or the
   [latest release](https://github.com/letzbefr4nk/lgb-companion-releases/releases/latest)) and
   download `lgb-companion-<version>-setup.exe` under **Assets**. The "Source code" files
   aren't the app. Pick the release marked **Latest**; ones marked **Pre-release** are beta
   versions for Beta testers.
2. Run it. It installs for your Windows user only and doesn't need admin rights.
3. **Windows SmartScreen** may say "Windows protected your PC", because the app isn't
   code-signed yet. Click **More info**, then **Run anyway**. Only do this for a file you
   downloaded from the link above.

Needs Windows 10 or 11 (64-bit).

## Updates

The app checks for updates by itself and installs them when you choose (Settings > General >
App updates). After an update, a short note shows what changed; every version's notes are in
Settings > What's new.

**Coming from 1.x?** Version 2.0 is rebuilt on a new base, so 1.x can't update to it by itself. Uninstall LGB Companion first (Windows Settings > Apps > Installed apps), then install 2.x from the download above. Your settings, tabs, notes and checklists stay on your PC and are there again after the install; you only need to sign in with Discord once more. From 2.0 on, updates install by themselves again.

## Your privacy

- The app never reads, changes or connects to a game, its files or its process. The Play button
  only starts the game, like a desktop shortcut.
- It downloads game info from our content site and updates from this repo.
- Signing in with Discord shares your Discord name, picture and server roles with the app's
  server, only to check that you're a member and what you're allowed to do.
- Reports you send (and any screenshot you attach) go to our staff in Discord for review.
- No ads, no tracking.

## Help

Settings > About.
